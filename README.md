# 🏠 Real Estate Management System

## 📌 Project Overview

The **Real Estate Management System** is a modern web-based application developed to simplify property buying, selling, and renting processes. This platform provides users with an easy-to-use interface along with AI-powered features to enhance user experience.

---

## 🎯 Objectives

* To create a centralized platform for property management
* To allow users to search, compare, and enquire about properties
* To reduce manual work and improve efficiency
* To integrate AI features like chatbot and recommendations

---

## 🚀 Features

* 🔍 Search and filter properties by location, price, and type
* 🏠 Buy, sell, and rent properties online
* 📩 Inquiry system for buyers and agents
* 🤖 AI-based chatbot for instant support
* 📊 Property price prediction (AI feature)
* 👤 Role-based users (Admin, Agent, Buyer)

---

## 🧩 System Modules

* **User Module** – Search properties, send inquiries
* **Agent Module** – Upload and manage property listings
* **Admin Module** – Manage users, properties, and system data

---

## 🗄️ Database Structure

* **Admin Table** – Stores property details
* **User Inquiry Table** – Stores customer inquiries
* **Agent Table** – Stores agent information

## 💻 Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/snehalsarvade02-afk/real-estate-project.git
```

2. Navigate to project folder

```bash
cd real-estate-project
```

3. Install dependencies

```bash
npm install
```

4. Run frontend

```bash
npm start
```

5. Run backend (Flask)

```bash
python app.py
```
